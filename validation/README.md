# Data Validation and Troubleshooting

This folder documents data-quality checks and troubleshooting performed during
the project.

During data preparation, an inconsistency was identified in the GDP per capita
dataset involving the year used for comparison. Validation checks were used to
trace the discrepancy, correct the underlying data, and rerun the affected
analysis.

The accompanying PDF contains notes documenting the troubleshooting and
validation process.
