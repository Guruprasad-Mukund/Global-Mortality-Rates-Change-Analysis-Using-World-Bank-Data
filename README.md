# World-Bank-Global-Mortality-Analysis
Analysis of global mortality rate changes from 2000–2019 using World Bank data on GDP per capita, health expenditure, and elderly population, with SQL, Python, visualization, and regression modeling.

How did mortality rates change across countries from 2000 to 2019 based on changes in GDP per capita, health expenditure per capita, and % of the population that is age 65+?
